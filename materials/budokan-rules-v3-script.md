# 開会式のルール説明・司会台本

司会向け。本文1〜12で約6分。13〜17は質問用の補足。読み上げ用の短い台本は opening-ceremony-runbook.md を使用する。

この版は最新の演目・SNS再検討メモを反映。価格、労働報酬、移動枠、機材・ギミックは未確定。開始時刻を変更する場合は固定時刻を更新する。

## 1. 武道館スペシャルライブ

司会①・司会②の漫才中はこの表紙を表示。漫才を終えてから次へ。BGMを司会の声が聞こえる音量へ下げる。

## 2. いまのファン数ランキングを確認する

司会①：まずは現在の順位を確認しましょう。
オペレーター：公開済みの budokan-rules-v3.html を使い、順位は自動で読み込む。2枚目で必要なら「順位更新」を押す。順位・ファン数・取得時刻を表示する。取得に失敗したときは前回の表示を消してエラーを示す。参加者ページへ切り替えて確認する。PPTX/PDFには順位データを焼き込まない。
司会②：ここまでの首位にも、追い上げるグループにも、まだ最後のステージがあります。

## 3. アイドルは演目を披露し、古参ファンは応援する

司会①：グループの挨拶から始めて、選んだ演目を披露してください。ダンス以外は挨拶も含めて3分です。ダンスは指定曲の1番を踊ります。全員が輝く姿を見せましょう。
司会②：古参ファンも応援で盛り上げてください。グループカラーの装飾も評価に入ります。出入りと転換は司会の合図に従ってください。
運営メモ：演目に使う音源、実尺、道具、入退場の動線を開演前に確認。ダンスが3分だとは断定しない。

## 4. 武道館は5項目60点、3人の平均点で評価する

司会①：武道館はこの5項目です。各審査員が60点満点で採点して、3人の平均点を使います。
司会②：衣装とグループカラーの装飾、面白さ、古参ファンの盛り上がり、そしてアイドル全員が輝いているかを見ます。

## 5. 最後にファン数が最も多い組がメジャーデビュー

司会②：1点がファン1万人。武道館では最大60万人を獲得できます。全6組が終わってから一括で反映し、最後のファン数でメジャーデビューが決まります。
司会①：同じファン数なら武道館の平均点、さらに同点なら「アイドル全員が輝いているか」の評価で決め、そこまで同じなら共同受賞・共同メジャーデビューです。

## 6. さあ、ステージへ。

司会①・司会②：それでは、最初のグループを紹介します！
オペレーター：出演順は別途確定した進行表を優先する。司会の紹介に合わせて演目のBGMを再生する。お題を選んだ順と出演順を混同しない。

## 当日用に確定する項目

- GB価格・労働報酬、SNS評価基準と減点の限度。
- 台車の型番と乗車・走行の許容条件、距離と乗り替わり方。
- 5分実施・10分移動と、17:20に戻る行程の実測。
- BGM、音源の尺、振付資料、演目道具と実施条件。
- 楽屋6区画の使用可否と出演順。
