# 最新の変更と次のリハーサル

## 決定したこと

- 労働バトルは中央食堂前・台車リレー企画（機材条件確認待ち）。合同ロケは医学部噴水前・合同ロケ、たけが担当。侍は欠席・担当なし。会場Dはアツコン。
- シャネル・スーダンはツアー開始後から本部、17:30から武道館司会。本部はシャネル受付・スーダン入力の分担案。森本が全体操作・質問・抽選・記事・LINE。
- 衣装は各ツアー会場の披露前に購入・着用。その衣装も実物をビジュアルで採点し、購入だけでは点を足さない。200GB・合計2セットは仮案。
- 16:30頃の途中首位1組へスキャンダル、最下位1組へ神対応。成功＋5万人。同率は抽選1組ずつ、同じ組を両方に選ばない。対象は登録後固定。
- 突撃前にボンボ・グッドマンの片方が全体LINEへ架空ファン役で「幻滅…」の書き込み。記者役は「こんな書き込みがあるんですけど」と首位へ突撃取材。その後ファン役へ切替えて最下位を訪問する進行案。
- 開始がずれたら開演・締切・スタッフの予定も全体でずらす。LINEは森本が確認して手動投稿。

## 画面の使い方

1. [運営ページ](https://idol-ekiden-control.coolmyna3.chatgpt.site/admin)でリハーサルを選択し、台帳JSONを保存。
2. 管理者の「予定・お題」で開始時刻を変更して適用。全11予定、6組のルート、スタッフの予定を同じ分だけ移動。スキャンダルの6候補を編集・保存できる。
3. 「記事の編集」に6候補の予告原稿がある。原稿を準備するだけではファン・GBは動かない。
4. イベント時刻を16:30に進め、管理者が「途中順位イベント・対象抽選」を1回登録。首位・最下位を固定し、記者役へ疑惑と現在地を伝える。原稿だけでは送信にならない。抽選後は不要な未共有候補を一覧から隠す。
5. 「スキャンダル進行」で対象アイドルの呼び名を入力し、架空ファン投稿・記者の台詞・森本の個別二択をコピー。投稿→記者取材を確認して記録し、森本がチームLINEへ口止め200GB／謝罪動画の二択を送る。次に最下位にファン役訪問。ステージ中は中断しない。取材16:30〜16:35・神対応16:35〜16:45は移動未実測の目安。厳しければ1人ずつ分担。
6. 首位の対応は16:45までの受信を記録。口止めは200GB支払・ファン増減0。謝罪動画は全体LINE投稿済みを本部が確認し、動画の完成度・理由と−10万〜＋3万人を直接入力（上限＋3万は仮）。最下位の応答・紹介・決めポーズを確認し「神対応イベントの結果」で＋5万人／未成立0を記録。動画・原稿を確認後、森本が全体LINEへ。
7. 16:50以降「スキャンダル結果確定」を登録。謝罪なら疑惑記事と動画評価・実増減記事を別々に確認して全体公開。口止めなら記事0本、掲載見送り記事もなし。最初の全体LINE投稿は残る。他5組への未対応減点なし。
8. オタ芸は「労働の報酬」、合同ロケは「合同ロケ労働（2組）」で両組へ同時登録。会場衣装は「GBで購入」で受渡し会場を選び、採点前に登録する。
9. 「スタッフの予定」で名前を選択・印刷できる。侍は欠席を表示し担当枠なし。
10. 全6組の武道館点を照合して進行を「結果公開」にすると、参加者トップと[結果ページ](https://idol-ekiden-control.coolmyna3.chatgpt.site/results)に受賞・全順位・5項目・GB、CSV・印刷を表示。共同受賞にも対応。

旧方式の全組予告が既に記録された台帳は旧方式で最後まで処理できる。履歴・残高は保持し、新方式は予告前の台帳で試す。新方式では対象抽選は再実施できない。

確認・編集・共有済み原稿や履歴を予定変更で上書きしない。変更後の締切はLINEと原稿にも再連絡。リハのイベント時刻は実時間と独立し、森本が手動で進める。変更は選択中の台帳に適用する。

## 原案・残る確認

スキャンダル候補はセンター選出じゃんけん／感動MCのカンペ／神歌唱の音源は古参／限定ファンサ使い回し／全員のソロ計画／ライバルのうちわ。予告前に編集可能、予告後は対象のお題を固定。現在は口止め料か謝罪動画の二択。話題化・固定＋2万方式は以前の記録用として保持する。動画は説明・謝罪・今後の対応を盛り込み、本部が完成度を見て人数と理由を決める。

オタ芸の尺・音源・報酬、合同ロケのペアと動画リレー、衣装在庫・30秒受渡し、歩行時間、記者訪問から神対応への移動、武道館中の本部入力代行と審査3名をリハで確認。16:30時点は回った会場数の違いを含む途中順位。対象を決める直前まで届いた採点を反映し、一度決めた対象は入れ替えない。詳しくは[具体案](event-proposals.md)。
