印刷はHTMLをブラウザで開き、A4・背景の印刷をONにして確認。採点票CSVは表計算へ取り込めます。資料の氏名はスタッフ共有用です。正式な公開範囲はスタッフ本人と確認してください。

ルールを変更したら、まず正本→計算・画面→資料→シミュレーションの順に更新し、価格と締切の食い違いを確認します。
