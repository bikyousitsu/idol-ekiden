# イベントカード・受付の共通条件

すべて試運転案。チーム名・担当名・成立時刻・台帳番号をカード裏または記録欄に残す。報酬の正本は `data/rules.json`。同じ仕事の再申請は、台帳で確認して二重登録しない。

## 古参ファン営業①「推しの30秒プレゼン」

- 担当：アレックス／侍／アツコン。所要2分。各チーム1回、200GB。
- お題：「推しの魅力を3つ、30秒で紹介してください」。古参ファン2人以上が一言ずつ、アイドルが最後に決めポーズ。
- 成立：3つの魅力＋複数人の発言＋最後のポーズ。大声は不要。準備30秒、実演30秒、確認・登録1分。
- やり直し：30秒以内で1回。内容が面白いかどうかでは成否を変えない。

## 古参ファン営業②「ポーズ再現」

- 所要2分、1回、200GB。
- アイドルが3つの簡単なポーズを示す。古参ファンが同じ順序で再現。
- 成立：3つを全員で再現。座ったまま・上半身だけでも可。撮影または担当者の対面確認。

## 古参ファン営業③「応援コール制作」

- 所要2分、1回、200GB。
- グループ名と決め台詞を含む10秒のコールを作り、アイドルの紹介と合わせて披露。
- 成立：グループ名・台詞・古参ファン複数人の参加。小声でもリズムやジェスチャーで可。

## スポンサーCM「架空商品CM」

- 所要3分、1回、300GB＋2万ファン。17:00にスポンサー入金200GBが1回。
- 架空商品：「ケイテキソーダ」。お題の3語「ひらめき／推し／ケイテキ」を含む15秒程度のCM。アイドルが出演、古参ファンが監督・撮影。
- 成立：3語を含む／チームの出演／提出済み。別の商品名を指定した場合も、全チームで同じ条件とする。
- 配信：チームLINE→運営確認→全体LINE／ニュース欄。撮影許可のない場所で撮らない。

## ファンクラブ開設「会員募集」

- 所要2分、1回、100GB。17:00のファン数10万人につき50GB、上限300GBを1回だけ入金。
- ファンクラブ名・応援合言葉・アイドル全員を紹介する1枚の募集画像または文章を作る。
- 成立：3項目が揃っている。実際の会員の募集・個人情報収集はしない。

## 合同ロケ「ライバル共同CM」

- 所要4分、各チーム1回、各300GB＋3万ファン。出演者を奪う・移籍させる処理はない。
- ペア案：G1–G3／G2–G4／G5–G6。ただし現ルートでは同じ自由枠に同じ場所に集まれない組がある。確定前に集合地点と時刻を設けるか、以下の動画リレーを標準にする。
- 実演：各組10秒自己紹介→相手の魅力を1つ紹介→全員で「推しは違っても、舞台は一緒！」。
- 動画リレー：片方が15秒の導入、相方が15秒の応答を別の時間・場所で撮影。森本が同じ案件番号で2本を確認して両方へ登録。編集・合成は成立条件にしない。
- 成立：2組が各1本提出／相手の名前または番号が入る／決め台詞が入る。相方未提出なら期限前に運営役を代役にする救済案（事前了承が必要）。

## スキャンダル「週刊ケイテキ」

- 全チーム1回、16:00チームLINEへ送付、16:45締切、16:50記事公開。
- G1：寮食を二重に食べていた疑惑。G2：自分のグッズを買い占めていた疑惑。G3：スポンサーの商品名を間違えた疑惑。G4：古参ファンに荷物を全部持たせていた疑惑。G5：楽屋で決めポーズだけ練習していた疑惑。G6：ライバルのうちわを隠し持っていた疑惑。配布の割当は仮。
- 全員へ「以下は今回の企画だけの架空ニュースです」と明記。運営の写真演出は本人の了承を得てから行う。参加者の実話・私生活・第三者を題材にしない。
- もみ消し：200GB、増減0。運営「広報対策費として200GBを処理します。これで対応完了です」。未払いは完了にしない。
- 釈明：30秒程度、「まず／実は／これから」の3語を使って疑惑への説明と今後の宣言。成立で＋2万、失敗−3万。
- 話題に乗る：疑惑を入れた15秒程度の架空CM／コント、最後にグループ名。成立で＋3万、失敗−3万。
- 未対応：−3万。提出時刻をLINE受信時刻で判断。運営都合で確認が遅れても期限内提出を未対応にしない。
- 代替：録画せず担当者の前で実演。難しい場合のやり直し1回・提出猶予の扱いは運営会議で確認。

## 任意SNS「ツアーレポート」

アイドルの投稿は15分に1回、古参ファンの会場レポートは各会場1回。承認1件＋1万人、全SNSと会場レポートを合算して各チーム最大4件・4万人。成立：チーム番号／撮影会場またはお題／アイドルと古参ファンの働きが分かる1枚または短文。スポンサー・合同ロケと同じ作品を二重申請しない試運転案。巡回が投稿番号を付けて森本へまとめて送る。

## 武道館レッスン

300GB・1回。購入で加点しない。演目のお題、3分の構成例、出演の分担を紙またはチームLINEで渡す案。早帰り組だけ対面指導が長くなる形は避け、同じ資料を購入チーム全員へ同じ時刻に届ける。レッスン内容の早期開示時刻は運営会議で決める。
