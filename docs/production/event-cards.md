# イベントカード・受付の共通条件

労働ポイントの場所は主催者指定、内容・担当・報酬の細部は試運転案。チーム名・担当名・成立時刻・台帳番号をカード裏または記録欄に残す。報酬の正本は `data/rules.json`。同じ労働の再申請は、台帳で確認して二重登録しない。

## 労働バトル「台車リレー案」（設備条件確認待ち）

- 中央食堂前に2組同時集合。アイドルを台車に載せてリレーする希望へ変更。台車仕様・人の乗車用途が未確認で、実施確定ではない。
- 押すのは古参ファン、各チームの古参ファン全員が走る役割は決定。ただし台車の乗車・走行用途は未確認。アイドル1名ずつ交代するか、乗車人数・コース距離・周回・乗降方法は未決で、5分以内で可能とはしていない。
- 普通の荷物台車の耐荷重だけで乗車可能としない。仕様未確認なら人を載せた試走をしない。
- 台車の種類判明後に低速・平坦区画・立乗りしない・通行と分けたコース等を検討する案。条件を並べただけで実施可能と扱わない。
- 比較は同じ区間・同じ周回数と運営確認を前提にする案。勝敗基準の細部は未決。報酬は勝者だけ500GB・敗者0GB、各組1回。各200GBの参加報酬は廃止し、未実施で自動登録しない。
- 人を載せない代替は本番前の相談候補だけで、主催者了承済みとはしない。台車・コース・進行を確認してから成立条件カードを確定する。

## 初期案の保管（以下3種は本番おすすめから撤回）

推しプレゼン・ポーズ再現・応援コールは、現行の労働バトルとは別の初期案として残す。本番の受付・報酬対象には追加しない。以下の200GB等は旧案の内容で、追加報酬の約束ではない。

### 推しプレゼン（初期案）

- 所要2分。各チーム1回、200GBという初期案。
- お題：「推しの魅力を3つ、30秒で紹介してください」。古参ファン2人以上が一言ずつ、アイドルが最後に決めポーズ。
- 成立：3つの魅力＋複数人の発言＋最後のポーズ。大声は不要。準備30秒、実演30秒、確認・登録1分。
- やり直し：30秒以内で1回。内容が面白いかどうかでは成否を変えない。

### ポーズ再現（初期案）

- 所要2分、1回、200GBという初期案。
- アイドルが3つの簡単なポーズを示す。古参ファンが同じ順序で再現。
- 成立：3つを全員で再現。座ったまま・上半身だけでも可。撮影または担当者の対面確認。

### 応援コール（初期案）

- 所要2分、1回、200GBという初期案。
- グループ名と決め台詞を含む10秒のコールを作り、アイドルの紹介と合わせて披露。
- 成立：グループ名・台詞・古参ファン複数人の参加。小声でもリズムやジェスチャーで可。

## スキャンダル「架空ファン投稿から週刊ケイテキ取材へ」

- 対象は16:30頃の途中ファン数で首位1組だけ、1回。全組1回の旧案は撤回。同じ時点の全組のファン数・会場消化数を記録し、同率首位は抽選1組、以後選び直さない。途中の会場消化数の差を含む演出で、全組完遂の評価とは別。
- シャネル・スーダンは15:30以降本部。シャネルが受付・動画完成度確認、スーダンが台帳入力・照合の案。森本が抽選・対象固定・マネージャー連絡・記事・全体LINE投稿。たけは合同ロケ、アツコンはD固定で兼任しない。
- 最初にボンボ／グッドマンの片方が全体LINEへ **【アイドル駅伝・架空ファン役】**「グループ{{番号}}の{{アイドル役の呼び名}}さんが過去に{{今回だけの架空設定}}してたんだ、幻滅…。※イベント内の演出です」と手動投稿。対象名・お題は送付前に差し替える。実際の過去や噂は使わない。
- その後 **【週刊ケイテキ・架空記者役】** として首位へ「こんな書き込みがあるんですけど、どうなんですか？」と取材。記者役は決済・独断判定をせず、ステージを中断しない。
- 取材後、森本がマネージャー役でチームLINEへ「記事になるみたい。16:45までに、200GBの口止め料か、全体LINEに上げる謝罪動画か選んでください」と手動連絡。話題化は廃止、二択のみ。
- **口止め料**：200GBを本部で決済確認。ファン増減0、疑惑記事・動画対応記事・掲載見送り記事を含め記事は一切なし。後続の取材動画・疑惑の転載も全体LINEへ出さない。ただし最初の架空ファン投稿はLINE上に残り、雑誌記事を止める処理と区別する。
- **謝罪動画**：本人／チームまたは運営が全体LINEへ手動投稿。本部が完成度を確認して−10万人〜＋3万人を直接入力（上限＋3万は仮値を維持）。理由・担当・動画参照・全体LINE投稿済みを記録。30秒程度の案で、疑惑への応答・謝意や今後の説明・グループの演出を確認する。固定＋2万等の旧判定は廃止。
- ファン数は0未満にしない。記事には入力した減少幅だけでなく、実際に減った人数を記載する。未対応は従来仮案の−3万人で、動画完成度の下限−10万人と区別する。対象外5組へ未対応減点をしない。
- 16:45まで対応受付。期限内の投稿記録は本部の確認が遅れても有効。16:50以降に結果反映し、謝罪動画の場合だけ「疑惑記事」「動画対応／ファン増減記事」の2本を下書き確認後に公開する。動画URL等は手動差替え。
- 記者訪問は16:30〜16:35、最下位神対応は16:35〜16:45の目安。徒歩未実測、厳しければ1人ずつ各対象組へ分担。神対応動画は確認後に森本が投稿する。対面だけの謝罪実演を動画提出と同じ扱いにする旧案は撤回。
- お題候補はセンターじゃんけん／感動MCカンペ／口パク音源が古参／限定ファンサ使い回し／全員ソロ計画／ライバルうちわ。原案は `event-proposals.md`。どれもアイドル役の架空設定で、実在人物の私生活や第三者の噂を題材にしない。

## 神対応イベント「初めてのファンが来た！」

- 対象：スキャンダル対象と同じ16:30頃のファン数で最下位1組を選び、1回だけ訪問。同率最下位は抽選1組。同じ組が首位・最下位両方になった場合は最下位を別組から選ぶ。記録後は対象を変更しない。
- ボンボ／グッドマンは首位への突撃取材後、ファン役としてアイドルへ声を掛ける。2人共演か、1人がファン役・もう1人が撮影かは進行案。徒歩が厳しければ一方が首位の記者役、他方が最下位のファン役を担当する。会場披露を中断せず、停止できる場所・タイミングを森本が確認する。
- 役の台詞案：「今日初めて見たんです！ グループ名と決めポーズを教えてください」。アイドルが応答し、古参は呼び込み・応援・撮影を支える。
- 成功条件：ファン役への応答、グループ紹介、決めポーズ。確認後に＋5万人を1回だけ登録。上手さや本物の観客数で判定しない。不成立は加算なしとする案で、別の減点を付けない。
- 実演は1〜2分の案。スマホで記録し、確認済みの実演を森本が全体LINEへ手動投稿する。神対応の報酬とSNS報酬を同じ動画で二重申請しない。

## 到着時の衣装購入・着用

- 場所に関係なく購入でき、ステージ採点後も購入可能。スタッフが残高・チーム合計の購入上限・在庫を確認して購入入力と現物受渡しを行う。ビジュアルは披露時の実物を評価し、過去の採点は自動変更しない。
- 価格200GB、1組合計2セットまでという既存の仮案を維持。会場ごとに2セットへ上限を増やさない。
- 着用した衣装の見せ方を手動のビジュアル得点へ反映する。購入数・価格の自動加点はなし。
- チームは事前に品を選び、会場では羽織・耳・ちょんまげ風などすぐ着けられる物を30秒で渡す案。販売追加で5分枠を延ばさないため実演確認が必要。素材の加工は自由時間へ回す。

## 任意SNS「ツアーレポート」

活動開始後、森本が各チームへ投稿を促す。原稿は1本ずつチームLINEへ送って森本の事前許可を得る→全体LINEへ本人／チームまたは運営が手動投稿→本部確認後に既存SNS報酬を登録。撮影・原稿には古参も参加し、5秒ごとに承認依頼を連投しない。アイドルの投稿は15分に1回、古参ファンの会場レポートは各会場1回。承認1件＋1万人、全SNSと会場レポートを合算して各チーム最大4件・4万人。成立：チーム番号／撮影会場またはお題／アイドルと古参ファンの働きが分かる1枚または短文。スポンサー・合同ロケ・謝罪動画と同じ作品を二重申請しない別作品ルールを維持。本部が投稿番号を付けて確認・登録する。

## 武道館レッスン

300GB・1回。購入で加点しない。演目のお題、3分の構成例、出演の分担を紙またはチームLINEで渡す案。早帰り組だけ対面指導が長くなる形は避け、同じ資料を購入チーム全員へ同じ時刻に届ける。レッスン内容の早期開示時刻は運営会議で決める。

## 武道館のお題選択・前説・BGM

- 演目は17:00清算と全24件のツアー採点を照合して固定したファン順位の上位から選ぶ。森本が残りのお題をチームLINEへ列挙し、1組ずつ選択。同じお題は最大2組まで。
- 送付後の1分カウントは手動で開始、1分は目安。超えても回答でき、自動締切・時間切れ抽選はしない。森本が声を掛けて続行。6組6分＋送信時間、17:10まで完了する計画。選択順の同率処理は抽選の仮案。
- 演目の選択順と出演順は別。出演順の旧案は未決で、上位から選んだ順にそのまま出演するものではない。
- 帰還前から共用棟へBGM。16:15頃までのループ開始が目安、開始ずれに連動。シャネルが開始確認、スーダンは入力、森本は全体。オフライン音源・借用スピーカーの電源／接続／音量／切替を確認し、選曲・音源調達は未決。
- 帰還BGM→司会時は音量を下げる→演目時はBGMを止めチーム音源→転換BGM→表彰BGM。前説以降の音源係は司会・審査・動画受付と分ける案で、1人へ全処理を集中させない。
