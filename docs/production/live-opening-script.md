## 17:23〜17:26 お題の披露方法・採点の説明

音響・本部：マイク優先。BGMは小さく、説明が聞こえればよい。

森本と確認したお題を、各グループで披露します。一年目全員に出番をつくり、古参ファンは応援で盛り上げてください。1組の実演は3分、入替は1分の仮案です。残り30秒はカードで知らせます。音源は司会の「どうぞ！」で開始します。
審査は3人、5項目の合計60点。「全アイドルが輝いているか」も評価します。着ている衣装も実物を見て評価します。各組のお題の具体的なやり方と、必要な道具・開始位置を確認します。

## 17:26〜17:28 現在のファン数順位を確認

ツアーお疲れさまでした！ 本部で照合した、ライブ前の現在順位を発表します。順位表の順にグループ名とファン数を読み上げます。同順位は同順位として紹介します。
ここからの武道館は1点につき1万人。全6組の審査を確認したあと、一緒に反映します。最後まで応援をお願いします！

## 本部と司会の確認

- 現在順位は17:20の取引終了後に森本が照合して合図する。Webの順位原稿は台帳に連動し、同率は同順位で読む。お題選択時に固定した17:00頃の順位とは別。
- 具体的な演目、音源、必要な道具、一年目全員の出番は事前に確認する。お題選択順は確定、出演枠の決め方は従来の別案で最終確認待ち。
- 5項目はファンの盛り上がり／ビジュアル／面白さ／アイドル全員が輝いているか／グループカラーの装飾。3審査員の項目別平均を足して60点。1点1万人、6組の採点照合後に公開。
- 「{{…}}」は確定した名前・お題・人数に差し替える。結果未確定のまま受賞名を読まない。
- 開演直前に全員へ質問する時間を作る。お題によって説明が長くなる場合は、各組への事前連絡で済ませる。
