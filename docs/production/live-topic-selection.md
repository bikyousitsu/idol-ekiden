# 武道館のお題選択

2026-10-12更新。ファン数上位から選ぶ・同じお題は最大2組・チームLINEへ残りを列挙・1分は目安で厳密に時間切れにしない、が決定事項。以下の開始時点・同率抽選・8候補の細部は仮案。

## 森本の手順

1. ツアー24件の採点、スキャンダル結果、神対応結果、定期収入の清算を照合する。17:00頃の開始を目指す。
2. 運営「武道館のお題」で選択順を1回固定する。ファン数順、同率内は抽選の仮案。固定後のファン増減で順番を入れ替えない。
3. 最上位の対象へ、画面に列挙された残りのお題・残り枠をチームLINEで手動送信する。送信後に「送信済み」で1分の目安を開始する。
4. 返答を確認してお題を確定する。1分経過は催促の合図で、自動打切りや無回答抽選はしない。次の組へ送る前に確定する。
5. 全6組で繰り返す。同じお題は2組まで。入力訂正にも上限がかかり、理由を台帳に残す。
6. 音源・必要な道具・一年目の出番を集める。17:10完了は目標で、6組×1分に送信/確認の時間が加わるため余裕を確保する。

全6組の確定後、参加者画面にお題一覧を出す。選択途中の順位抽選や返答タイマーは運営のみ。開演前の17:20現在順位確認は、この固定した選択順位とは区別する。出演順は別の運用案で最終確認待ち。

## お題候補（仮）

- 大喜利：お題3問に全員で回答
- モノボケ：共通の3道具で交代して披露
- ボディビル風ポーズ：紹介文と全員の決めポーズ
- 組体操風の床上ポーズ：立つ・座る群像ポーズ3つ
- ダンス：指定曲の短い音源で披露
- ショートコント：「こんなアイドルは嫌だ」
- リアクション芸：封筒のお題を無言で表現、古参が当てる
- ラップ：司会の8小節へ各人が返す

候補は既存の演目案を選択できるようにしたもの。曲・小道具・お題カードはリハで確定する。
