1. 開催日、共用棟の部屋、18条ステージの正確な地点、会場利用・音出しの条件。
2. 4会場間と共用棟の徒歩実測。G4〜G6の北→南移動と、G6の16:50クラーク像→17:20集合を重点確認。

4. 名簿13人と同時最大11人の司会交代が成立するか。スタッフ担当・欠席時の代行・審査員3人。
5. 仮価格、報酬、SNS条件、17:00入金、同点処理。最終は項目平均を合計して小数第1位に一度だけ丸める仮運用。源泉時間差がないか。
6. 合同ロケを同時撮影にするか動画リレーにするか。ペア・地点・相方不在の救済。
7. 演目一覧・出順希望の方法・レッスン内容の開示時刻。G1早帰りとG6遅帰りの準備差。
8. 衣装の在庫、握力計・縄・音源・スピーカー、実費予算の購入承認。
9. 撮影と全体LINE掲載の了承、顔出し不要の実演代替、雨天場所、ダッシュボードの公開方法。

## 60分の運営リハ

| 分 | やること | 合格条件 |
|---|---|---|
| 0–10 | 6組のデモ登録・初期600GB・公開画面 | G番号と色が正しく、全チームのGBとファンが見える |
| 10–20 | 1会場を5分で実演、紙→入力 | 25点上限、ファン換算、番号返信を確認 |
| 20–30 | 営業→購入→上限→訂正 | 2重登録を防げる、残高不足は買えない、訂正理由が残る |
| 30–40 | スキャンダル3対応と未対応 | 16:50一括反映、期限内受信は後確認でも有効 |
| 40–45 | 17:00一括入金を2回押す試験 | 二重入金を防ぐ／紙で記録できる |
| 45–55 | 武道館3名採点→同点→表彰 | 60点上限、平均・丸め・同点が決めたルール通り |
| 55–60 | 通信切断・バックアップ復元 | 保存版と紙から6組の状態を復元できる |

これは運用リハ案。実際の動作確認結果を日時と担当付きで記録する。モックテスト・仮想進行が通っても、当日の通信・複数端末同期・徒歩に対する保証にはならない。
