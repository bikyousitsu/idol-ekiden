# 司会・スタッフ台本

時刻は開始15:00の基準例。変更後は運営画面の「スタッフの予定」と参加者予定を照合し、台本・LINEの時刻を置き換えて読む。

読上げる数字は正本・台帳と照合。未確定の料金や時刻を当日の確定ルールとして読まない。

## 書き込みをもとに突撃：ボンボ・グッドマン

「週刊ケイテキの記者です。こんな書き込みがあるんですけど、△さん、事実なんでしょうか？ グループと古参の皆さんはどうお考えですか？」

ステージ中は待つ。正式な二択は突撃後に森本が個別連絡する。取材は1分程度の案。

## 取材後のチームLINE：マネージャー森本

「【マネージャー森本】こんな書き込みが出ているんですけど。記事になるみたいですよ？ {{締切}}までに、雑誌社へ口止め料200GBを払うか、謝罪動画を撮って全体LINEに上げるか選んでください。口止めなら記事なし。動画なら本部が完成度を確認し、ファン数を−10万〜＋3万人で増減させます（上限は仮）。」

口止め受付：「200GBの支払を確認しました。雑誌の記事は出ません。初めのLINE投稿は残ります。ファン増減はありません。」

動画受付：「全体LINEへの謝罪動画投稿を確認しました。本部で説明・謝罪の伝わり方・動画の完成度を見て、{{増減人数}}人、理由{{評価理由}}と記録します。{{結果確定時刻}}以降に反映し、疑惑記事と動画への反応・増減記事を確認して公開します。」

対象名と疑惑は運営が用意した役の内容へ差し替える。実際の過去を暴露する台本にしない。Webの「スキャンダル進行」では名前と締切に連動した原稿をコピーできる。

## 演目カードの仮案

| 演目 | 3分でできる内容 | 準備・道具 |
|---|---|---|
| 大喜利 | お題3問、各一年目が最低1回答 | お題カード・紙 |
| モノボケ | 共通の3道具で交代しながら披露 | 共通道具セット |
| ボディビル風 | 全員が紹介文と決めポーズ | 音源・呼出し文 |
| 組体操風 | 床に立つ／座る群像ポーズ3つ | マット任意。肩車・積上げなし |
| ダンス | 指定曲の1番または短い編集音源 | 曲・再生位置を統一 |
| ショートコント | 「こんなアイドルは嫌だ」 | 共通お題、各人の役 |
| リアクション芸 | 封筒のお題を見て無言で表現、ファンが当てる | お題カード。熱い物・辛味は使わない仮案 |
| ラップ | 司会の8小節へ各人が返す | 共通ビート・人への攻撃を題材にしない |

衣装は脱ぎ着しやすく歩けるものを使う。演目の細部と代替案は最終決定が必要。ラップの相手をシャネルにする場合は司会進行をスーダンに一時交代する。

## 最下位の神対応：ボンボ・グッドマン

首位取材後に記者役からファン役へ切替。16:35〜16:45を目安とする案で、徒歩時間は未実測。厳しければ1人が記者、1人がファン訪問へ分担し、チームのステージを中断しない。

「初めて見たんですけど、グループ名を教えてください！ みんなで決めポーズを見せてもらえますか？」

応答・紹介・ポーズの成立を本部へ連絡。本部が＋5万人を1回登録、森本が動画と原稿を確認して全体LINEへ。「神対応に感動、新規ファン5万人！」。取材・神対応の撮影役と移動はリハで確認する。

## 活動開始後の各チームLINE・BGM

森本は [LINE送信用原稿](manager-line-messages.md) の開始連絡・事前許可・ルール説明を各チームへ送る。投稿許可を先に取り、全体LINE投稿後に本部へ報酬確認。

早い組が帰る前に共用棟のBGMを開始（基準16:15頃・シャネル確認の担当案）。司会中は音量を下げ、演目開始はBGM停止→演目音源、入替はBGM、表彰は受賞用BGM。詳細は [武道館音響キュー](show-audio-cues.md)。
