# 武道館の帰還BGM・音源キュー

2026-10-12更新。帰ってきた参加者が入る時点で、共用棟「武道館」にBGMを流しておく。基準は開始15:00、ツアー15:30、開演17:30。時刻は仮の進行例で、運営画面「スタッフの予定」に連動するBGM目安を確認する。

## 帰還前の準備

新しい予定では全組の最後の活動が16:45〜16:50の仮案なので、**16:15頃までにBGMのループ再生を開始**する。実際の帰還は歩行実測で確認し、早く戻る組があれば開始を前倒しする。全体の開始が15分遅れた場合、この目安も16:30へ移る。

開始確認は本部のシャネルに依頼する案。スーダンは台帳入力、森本は質問・記事・全体LINEを優先。ライブ中の音響操作は司会とは別の担当を決め、評価入力と同時に一人へ集中させない。

- 再生端末・スピーカー・接続ケーブル・充電/電源・予備を借用品で準備する。
- 帰還BGMを事前に端末へ用意し、ネット接続なしで連続再生できることを確認する。台帳用端末とは分ける案。
- 帰還BGM／各組の演目音源／表彰BGMを分け、曲順とファイル名を音響担当が見て分かる形にする。具体的な曲は未決。
- 客席・司会位置で音量を確認。BGMを流しながら受付の声が聞こえること、マイクの声が埋もれないことを確認する。
- 17:10の演目申告までに各組の音源・開始位置・終了合図・音源なしでよいかを集める。申告内容は森本が台帳と照合する。

## 操作する順番

| タイミング | 音響操作 | 合図・確認 |
|---|---|---|
| 16:15頃まで | 帰還BGMをループ開始 | シャネルが再生・音量を確認する案 |
| 帰還・衣装準備・待機 | 帰還BGMを継続 | 受付の声が通る音量 |
| 17:20〜17:23 漫才 | BGMを下げる／声が埋もれれば止める | シャネル・スーダンの掛合い |
| 17:23〜17:26 披露方法の説明 | マイク優先でBGMを小さく | 尺・道具・開始合図・採点を説明 |
| 17:26〜17:28 現在順位確認 | BGMを小さく | 森本の照合合図後、現在の順位表を読む |
| 17:28ライブ導入 | BGMを下げ、紹介の最後で止める | 司会と音響が目線・合図を合わせる |
| 各組の演目開始 | BGM停止→その組の演目音源 | G番号・曲名・開始位置を声に出して照合 |
| 演目中 | 演目音源だけ | 停止合図と尺を確認。別のBGMを重ねない |
| 演目終了・入替 | 演目音源停止→短くBGM | 紹介が始まったら音量を下げる |
| 全組終了・結果照合 | 待機BGM | まだ受賞音を鳴らさない |
| 優勝発表 | 司会の発表に合わせ表彰BGM | 森本の結果確定合図を待つ |
| 写真・終了 | BGMを継続し終了後停止 | 忘れ物・物品返却を確認 |

## 音源が出ないとき

曲が流れなければ司会が一度止め、音響がG番号・接続・再生位置を確認する。予備端末へ切り替えるか、チームに音源なし実演の可否を確認する。機材の不調をグループの演技失敗として扱わず、再開時刻・事情を森本へ記録する。

この資料は当日の操作手順であり、Web画面から会場スピーカーを自動再生する機能は付けていない。選曲、借用品、音響担当と現地の音出し確認を次のリハで確定する。
