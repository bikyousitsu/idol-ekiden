# ネットニュースの運用

ニュースは「ケイテキ!ニュース」の架空記事として演出する。媒体名は「週刊ケイテキ編集部」。参加者向けの記事は一件ごとに独立したURLを持ち、ログインせず読める。編集・採点は運営画面で行う。自動下書きは確定した記録から作り、公開する前に森本または担当運営が内容を確認する。

## 公開からLINE投稿まで

1. 運営画面で記事の下書きを開く。タイトル、要約、本文、対象グループ、架空コメントを確認する。
2. 実際に確認した見せ場や発言だけを追記する。映像・写真がなければ、撮影したような表現にしない。参加者の写真・動画は掲載可否を確認する。
3. 公開範囲を確認して公開する。ログインしていない参加者の見え方で、記事とリンクを確認する。
4. 森本が「短い見出し＋記事URL」を全体LINEへ手動投稿する。記事作成や公開だけではLINEには届かない。
5. 誤りがあれば運営画面で訂正する。進行・得点に関わる訂正はLINEにも要点を流す。記事の訂正だけで得点を変更せず、必要な得点訂正は記録を残して別に行う。

投稿例：

> 【ケイテキ!ニュース】ライバル2組が合同CMで共演！
> （公開された記事URLをここに貼る）
> ※企画内の架空ニュースです。現在の順位はダッシュボードで確認できます。

## スキャンダルの公開を分ける

- **掲載予告**は全体公開しない。原稿確認後に「チーム用リンク発行」で鍵付きURLを作り、森本が対象チームLINEへ個別に伝える。全体ニュース一覧・検索には出さない。リンクを転送された相手も読めるため、対象チーム内で扱う。
- **結果**は16:50に全体公開する。各グループを独立した記事URLに分け、森本が必要な記事のURLを全体LINEへ流す。釈明・話題化・対応失敗・未対応は、運営が確定した結果に沿って記事を書く。
- **もみ消し**を選んだ組は「掲載見送り」とし、元のトピックを明かさない。本文だけでなく見出し、要約、コメント、画像、LINE紹介文にもヒントを残さない。ファン数の変動なしという結果だけを伝える。
- 単独のスキャンダル記事を手動で書く場合も同じ原則を守る。実際の個人の噂や不祥事は題材にしない。

## 架空コメントの使い方

コメント欄は、**すべて運営が作る架空コメント**。一般の参加者が実際に投稿したコメント・投票に見せない。「応援」「考察」「辛口」を混ぜ、各記事4〜6件を目安にする。賛同・反対の数字も演出用で、得点や実際の反応には使わない。各記事とコメント欄に、架空のイベント記事・コメントである表示を置く。

辛口は「宣伝が先行している」「見出しでハードルを上げすぎ」「本編を見たい」といった**架空の活動・売り方・結果へのツッコミ**にする。容姿・人格・属性の攻撃や、実在の噂を持ち込む表現は使わない。本人の本名・写真を使う記事では特に読み直す。架空コメントを何度も追加して、特定の参加者を標的にしない。

普通の活動記事は `mixed`、開幕や結果発表は `supportive`、架空の宣伝合戦は `spicy` の素材から選べる。辛口素材を使う場合も応援と考察を残し、運営が記事との相性を確認する。練習記事は練習モードだけで使い、本番の実施結果として公開しない。

## 公開直前の確認

- 確定した数値と記事の数値が一致しているか。記事の反応を根拠に報酬を足していないか。
- 「下書き」「追記してください」などの運営用文章を残していないか。
- 架空ニュース・架空コメントであることが分かるか。
- 掲載見送りの内容、非公開の採点、対象チームだけの掲載予告が混ざっていないか。
- 練習記事を本番データと混同していないか。
- 記事URLをログインなしで読めるか。運営画面のURLをLINEに貼っていないか。
