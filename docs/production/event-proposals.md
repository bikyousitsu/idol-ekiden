## 1. スキャンダルを「広報ごっこ」にする

本部配置はツアー開始15:30以降、シャネル・スーダンが担当。具体的な分担はシャネルが受付・成立確認、スーダンが台帳入力・照合という案です。森本は抽選・対象固定・記事・全体LINE投稿。小峰は医学部噴水前の合同ロケ担当で、本部受付へ戻す前提にしません。司会4人の同時活動は認められており、入場の交代制限はありません。武道館中にシャネル・スーダンが司会へ移る際の台帳代行は別途決めます。

**旧案の「全6組1回」は撤回。16:30頃の途中ファン数で首位1組だけがスキャンダル、最下位1組が神対応イベントを受けます。** 同じ時点の全6組のファン数と会場消化数を記録して対象を一度決め、以後の順位変化で選び直しません。同率首位・最下位は各候補から抽選で1組、同一組になったら最下位側を別組から抽選します。

この途中順位は会場消化数の差も含む演出用の順位です。全組が同じ会場を完遂した評価・最終順位とは別と参加者へ説明します。**主催者の「もっとアイドルの芸能ニュースらしく」という希望に合わせ、以下の6本を対象首位組に送るお題の候補として提案します。** 本人の実際の私生活を探す企画ではなく、アイドルという役の架空設定です。証拠写真は必須にせず、本人が選んだ場合だけ小道具で再現します。

### 対象首位組の選択肢と判定

| 対応 | 公開する成立条件 | 既存処理 |

| もみ消し | 対応を選び、200GBを支払える。担当が支払登録を確認 | −200GB、ファン増減0。結果記事は「掲載見送り」 |
| 30秒釈明 | 「まず／実は／これから」の3語を使い、届いた疑惑への説明と今後の宣言がある。動画または対面で担当が確認 | 成功＋2万人、失敗−3万人 |

面白さ・声量・本物らしさ・架空コメントの反応は成否に入れません。「30秒」「15秒」は既存カード同様の目安とし、秒単位の誤差だけで失敗にしない提案です。古参ファンは記者・広報・カンペ・撮影役を選べますが、追加の参加人数要件を勝手に加えません。

提出はチームLINEの動画、または本部受付担当への対面実演。動画は顔を映さず声と小道具だけでも条件を確認できるようにする案。担当が未達の箇所を伝え、締切内は修正1回を認める案です。修正回数・救済時間は採用前に全組へ同じ文面で示します。LINE受信時刻が期限内なら、確認待ちで未対応にしません。対面のためにルートを引き返す必要がある組には動画提出を案内します。

1. 予告前に全組へ「途中順位による演出」「首位1組に架空スキャンダル、最下位1組に神対応」「選択肢と成功条件」を説明する。

3. 本部シャネル／スーダンが首位組の対応を確認し登録する案。もみ消しは支払時にGBを処理し、疑惑は記事に出さない。D担当アツコンを受付へ呼び戻さない。神対応対象組は開会司会が訪問する。
4. 基準時刻16:45で受付を締める。期限内の受信・対面受付を照合する。
5. 基準時刻16:50の結果反映後、対象首位組の記事を確認して公開。森本が見出しとURLを全体LINEへ送る。対象外の5組には未対応の減点をしない。

上記は開始15:00の基準時刻です。開始を変更する場合は最新のイベント時刻表に置き換え、LINE用文章の締切もその表から読む運用にします。

### 結果記事の笑いどころ

釈明・話題化成功の記事には、実際に確認した一言だけを引用して内容を紹介します。例：「感動MCのカンペ疑惑」に対し、担当が確認した『感謝を一人も言い忘れないためのメモでした』を掲載。例文を参加者の実際の発言とみなさないこと。

架空コメントは「広報が上手い」「この勢いを本編にも」など演技へのツッコミにする案。センター案なら「総選挙の開票速報がグー・チョキ・パーなのは斬新」、カンペ案なら「『ここで泣く』のカンペ係まで紹介したら逆に見たい」、ソロ計画案なら「全員ソロ希望ならグループの解散理由も全員同じになりそう。まず本編が見たい」といった内容。**もみ消し記事のコメントは共通の掲載見送り用だけを使い、お題を推測できるツッコミは載せません。**

### 対象組の制作時間

16:30頃の予告から16:45締切まで約15分です。首位組にも次のステージと移動があるため、短い釈明・CMを作る3〜5分の停止時間を確保する必要があります。神対応訪問はステージ披露を中断せず、その後に1〜2分の安全な停留で行う案。全組へ演技例を開幕時に示し、対象決定後の長い相談を減らします。開始時刻の変更で締切をずらしても、停止時間と移動の実測は別途必要です。

### ツアー到着時の衣装購入

会場到着時、披露前に衣装を購入して着用できます。会場担当が購入入力→現物引渡し→ステージを担当。着用した衣装の見せ方は手動のビジュアル項目で評価し、購入数・価格の自動加点はしません。200GB・全会場合算で1組2セットまでという既存の価格・上限は仮案のままです。

5分枠へ販売を加えるため、チームLINEで事前に選び、羽織や耳などすぐ着けられる品を袋にして30秒で引き渡す進行を提案。新たに縫う・組み立てる作業はステージ枠に入れません。各会場在庫・予約・共通の購入上限を照合し、衣装のために次の組を待たせない設計を実測します。

## 2. 労働ポイント②・医学部噴水前の合同ロケ

**場所と合同ロケの採用は決定。2組同時の受付にするか、動画リレーを代替として認めるかは確認待ちです。** 現ルートでは2組の空き時間と場所が合わないため、同時受付を採るなら医学部噴水前での共通集合枠と待機場所をルート表へ追加する必要があります。代替を認めるなら同じ条件・報酬とし、移動のために実演方式を選べない組を不利にしません。

- 同時受付案：各組10秒の紹介、相手の魅力を一つ紹介、全員で共通台詞。説明・撮影・確認込み4分。古参がMC・撮影、一年目が出演。担当は小峰に決定。

- ペア候補は既存案G1–G3、G2–G4、G5–G6。開幕時に相手名と案件番号COL-01〜03を各組へ渡す。
- 各組が「自分のグループ名→相手の魅力を一つ紹介→『推しは違っても、舞台は一緒！』」を15秒で収録する。古参が番組MC、一年目が紹介やポーズを担当。
- 相手の魅力は自己紹介カードから引用してよい。相手を探して長距離を往復したり、スマホ編集で合成したりする必要はない。
- 所要：説明30秒、役割相談1分、撮影30秒、提出・確認1分。道具はスマホ、相手の自己紹介カードだけ。
- 成立：2組が各1本提出、相手名またはG番号が入る、共通台詞が入る。受付が案件番号で2本を照合し、同一の合同ロケ操作で両組へ報酬を登録する。
- 公開は二つの動画リンクまたは確認済みの紹介文で可。動画編集・合成は森本の必須仕事にしない。
- 相手が提出できない場合の運営代役は既存の未確定案。採用するなら全組へ事前告知し、運営代役で追加の報酬を発生させない。未決定のまま個別救済を約束しない。
