# 共通ルール・料金表（試運転版）

更新日：2026-10-11。数値の正本は `data/rules.json`。この文書は同ファイルを人が読める形にしたものです。GBはゲーム内通貨で、実際のお金とは別です。金額・報酬・15分枠・徒歩時間は未承認の仮案です。

## 合意済み

- 6グループ。15:00開始、17:30寮共用棟「武道館」開演。18:00終了は仮案。
- 一年目はアイドル、上の年目は古参ファン。チームで行動する。
- ツアーは4会場・各会場1チーム。演目の重複可。武道館は5項目60点。
- スキャンダルは全チームに1回。GB残高・ファン数・順位を全体公開。
- LINE投稿は運営が確認して手動で行う。

## 初期状態と勝利条件

各チーム600GB、獲得ファン0人で開始。古参ファンである参加者は離脱・推し変をしない。数字のファンは架空の新規ファン。ステージ点を1点＝1万人として加算する。最終ライブの加算後、獲得ファンが最も多いチームが優勝。余ったGBをファンへ自動変換しない。同点時は武道館合計→「アイドル全員が輝いているか」の点→同時デビュー（同順位・共同受賞）の順で判定する仮案。延長戦はしない。

## スキャンダル対応

全チーム1回、16:00予告→16:45対応締切→16:50結果記事（すべて時刻は仮案）。疑惑は運営が作った架空の設定。

| 選択 | 費用 | 結果 |
|---|---:|---|
| もみ消し | 200GB | ファン増減0。支払い完了で解決 |
| 釈明会見 | 0 | 条件を満たす30秒動画で＋2万人。失敗−3万人 |
| 話題に乗る | 0 | 条件を満たす15秒CM／コントで＋3万人。失敗−3万人 |
| 未対応 | 0 | −3万人 |

成功条件は提出前に同じ文面で伝える。笑いの大小だけで成否を決めない。顔出し・録画が難しい場合は担当運営への対面実演で提出可とする案。もみ消しのGBは支払い時に処理し、ファン増減は全チーム16:50に一括反映。減点と補償の記録は同じ台帳に残す。

## SNSと未確定の処理

- ツアークリア報酬は0GB。
- 承認されたSNS投稿は1件＋1万人。全SNSと会場レポートを合算して各チーム最大4件・4万人。アイドル投稿は15分に1回、古参ファンレポートは会場ごとに1回。スポンサーCMや合同ロケの同じ動画をSNS報酬へ二重申請する場合の扱いは事前に決める（本試運転は別作品のみ）。
- 未提出・判定訂正・締切を本番前に確認。AIが独自に点数や報酬を決める処理は採用しない。
