# 運営の初回登録と15分の動作確認

2026-10-11。画面・記事の改修後に、担当別の運営IDと参加者端末で確認する手順。確認済みの自動テストと、下記の実施結果は分けて記録する。

## 1. 森本の管理者登録

1. [運営ページ](https://idol-ekiden-control.coolmyna3.chatgpt.site/admin) を開く。
2. サイトを作ったChatGPTアカウントでログインする。
3. 初回だけ「所有者として運営を開始」を押す。登録済みなら採点画面へ進む。
4. 「採点・報酬」「記事の編集」「スタッフID」「台帳・設定」が使えることを確認する。
5. 初回登録を確認した後、初回受付設定を無効にする。設定変更はサイト側の配信にも反映する。

所有者と異なるアカウントは初回登録できない。所有者のChatGPTログインは、運営IDの発行と復旧に使う。スタッフにはChatGPTへの登録を求めず、管理者が割り振った運営IDと自動発行されたパスコードでログインしてもらう。実際のID・パスコード・台帳・ログイン画面の個人情報は公開GitHubへ保存しない。

## 2. 担当別の運営IDを発行する

1. 管理者が「スタッフID」タブを開き、担当名と運営IDを決める。
2. 入力担当には編集者権限を選ぶ。森本本人のIDを作る場合は管理者権限を選ぶ。
3. 発行時だけ表示されるパスコードを控え、運営IDと一緒に本人へ個別に渡す。全体LINEや公開資料には載せない。
4. 本人が運営ページでログインし、担当名が表示されることを確認する。操作履歴にはこの担当名が残る。

IDだけではログインできない。パスコードを紛失した場合は、管理者が再発行して新しいものを個別に渡す。担当から外れた人のIDは無効化する。共通のIDを回して使わず、誰が入力したか追えるようにする。

ログインから8時間でセッションが終了する。5回連続でログインに失敗した場合は15分待ってから再試行する。当日は開始前にログインし、端末変更や再ログインに備えて自分のIDとパスコードを確認できるようにしておく。

## 3. 誰に入力を任せるか

IDを発行する人は、実際に記録を入力する担当に絞る。以下は現在の仮配置をもとにした候補で、担当が確定した人から発行する。

| 人 | 担当案 | ページの使い方 |
|---|---|---|
| 森本 | 全体PC・質問・記事公開・LINE投稿 | 管理者 |
| たけ | 合同ロケ・合同ロケ | 入力担当の候補 |
| たけ・佐伯・ぷし・アツコン | 固定4会場の説明・採点 | 会場から直接入力する場合に追加 |
| アレックス | 労働バトルの受付案 | 労働バトルの勝敗を直接入力する場合に追加 |
| ボンボ・グッドマン・シャネル・スーダン | 記者会見・武道館の司会 | 司会のみなら参加者ページの閲覧で足りる |

会場が紙やLINEで採点を伝え、森本・本部シャネル／スーダンが代行入力する運用も可能。どちらを使うか、受付番号の付け方と合わせて運営リハで決める。採点済みかは台帳を照合し、同じ報酬を二度入れない。

## 5. 15分で試すこと

リハーサル台帳が空なら下記の数値で進める。既に記録がある場合は先にJSONバックアップし、記録済みの活動を確認する。数値例を合わせるために既存データを消さない。

| 目安 | 操作 | 確認すること |

| 3–5分 | リハーサルを選び、進行を「全国ツアー」、時刻を15:30にする | 参加者側のリハーサルページにも状態が出る。初期は6組600GB・0ファン |

| 7–9分 | G1に衣装を1セット購入し、会場Aを[4,3,4,7]で採点 | 800→600GB、購入だけではファン加算なし。18点の採点で18万人になる |
