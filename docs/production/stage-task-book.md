# ツアーお題集・採点の具体例（運営用）

既存の25点配分を変えない補足案。事前の模擬プレイで5分に収まることを確認する。下の正答・計測基準を途中で変えない。

## A お笑い／たけ

0:00説明、0:20準備40秒、1:00コント60秒、2:00モノボケ60秒、3:00採点・返却。

コントのお題は全組「こんなアイドルは嫌だ」。全アイドルに一言ずつ。モノボケは共通の「タオル・紙コップ・うちわ」から1つ選び、準備20秒→実演40秒。難しいボケの成功だけを条件にせず、役の分担、相手の受け、最後まで演じる姿を観察する。

おもしろさ5：意図が伝わるか、展開やオチがあるか。瞬発力5：指定時間と道具で成立するか。古参ファン5：応援・振り・場面づくりに関わったか。ビジュアル10：衣装・色・ポーズの見せ方。採点票の共通目安で0〜上限。

一般知識ではなく、計算・観察・イベントルールで揃える。各セットは同じ構造。説明後2分30秒で、基本3問→面白回答1問→古参ファン記憶1問。

かしこさ5：正答0問0点／1問2点／2問3点／3問5点の仮案。面白回答5：「このグループの新しい特典、どんなもの？」→20秒準備、アイドルが各1案。古参ファン能力5：アイドルが「リボン・ソーダ・うちわ・舞台」を見せずに1度読み、古参ファンが再現。4語正順5点／3語4点／2語3点／1語1点／0語0点の仮案。ビジュアル10は共通基準。

## C スポーツ／ぷし

0:00説明、0:30練習30秒、1:00縄30秒、1:30握力測定60秒、2:30番組紹介30秒、3:00採点。

8の字跳び5：各人は飛べる範囲で順番に入り、古参ファンも縄回しや声掛けを担当。30秒の成功延べ回数0回0点／1〜3回1点／4〜7回2点／8〜11回3点／12〜15回4点／16回以上5点（仮、10人程度の模擬プレイで調整）。縄跳びが難しい人は紹介・回し・カウントに参加。人数による有利が大きい場合は代表者の数を揃える。

握力チャレンジ5：アイドル1名と古参ファン1名が各1回、事前に「何kgか」を予想。絶対的な握力の強さより予想との差で競う案。2人の平均誤差2kg以内5点／4kg以内4点／6kg以内3点／8kg以内2点／それ以上1点。測定ができない場合の代替基準は機材確認時に決める。**握力計の借用が前提、機材なしで実施可能とはしていない。**

番組中の面白さ5：挑戦紹介・結果発表を番組風にできたか。ビジュアル10は共通。測定・縄の結果は口頭で記録し、採点票の裏に残す。

## D ダンス／やり

0:00説明、0:20曲・拍の練習40秒、1:00サビ実演60秒、2:00応援付きアンコール30秒、2:30全員の決めポーズ30秒、3:00採点。

曲は本番前に1曲・開始位置を揃える。音源使用と会場音量を確認。リズム感5は揃った拍と動き、ファンの熱量5は応援の参加と工夫、やりきり5は最後までの表現と全員の関与、ビジュアル10は色・衣装・ポーズ。声量や難しい振付だけで評価しない。

覚えるのが苦手な人向けに、同じ8カウントを繰り返す簡単版を用意する。どの版でも満点に到達できる評価にする案。

## 採点キャリブレーション

運営が同じ模擬演技を見て個別採点→各項目2点以上の差があれば理由を話す→目安を揃える。価格・衣装購入回数の情報を見て点を付けない。具体的基準はこれ自体が仮案なので、運営の了承後に参加者へ示す。
