# LINE・AI・ダッシュボード

更新：2026年10月9日。

## 目指す連絡の形

参加者全体のLINEグループと、チームごとのLINEグループを作る。一つのイベント用公式アカウントを各グループに招待し、送り先を選んで配信する。

| 配信先 | 内容の例 |
| --- | --- |
| 全体 | 集合連絡、順位速報、広告、公開ニュース、ライブ案内 |
| 特定チーム | 報酬、残高、限定情報、スキャンダルの事前通告 |
| 全チーム個別 | 全チームに同じお題や帰還通知を届ける |

LINE公式仕様では、グループIDを宛先に指定して投稿できる。各グループへの配信は個別に処理する。グループに同時参加できるLINE公式アカウントは一つ。

## AIに担当させたいこと

- ミッション結果から、芸能ニュースや架空のファンコメントを作る。
- チームが購入した広告の文章を作る。
- 設定した条件に沿ったスキャンダル記事やイベント告知を作る。

得点や資金は台帳の確定値を参照し、重要な連絡は運営の確定内容を送る案。AIのモデル・費用・生成範囲・確認方法は未決定で、まだ実装していない。

Dotsについても相談したが、確認した公式案内の標準連絡先はChatGPT・Slack・Teams。今回のLINE連絡はイベント用ボットで構築する方向。Dotsを運営の企画整理や記事案作成に使うかは未決定。

## ダッシュボードの候補

| 画面 | 表示・操作する内容 |
| --- | --- |
| 全体向け | 順位、獲得ファン数、芸能ニュース、広告、ライブ案内 |
| チーム向け | 自チームの資金、ミッション状況、取得物、限定情報 |
| 運営向け | 採点、入出金、報酬、送り先指定、記事作成、結果確定 |

画面構成、更新頻度、公開情報の範囲、チームの本人確認、動画提出・保管は未決定。現時点であるのはLINE配信の試作画面のみ。

## 完了・確認済み

- LINE公式アカウントを作成したとの報告あり。
- Messaging APIが「利用中」であることを画面で確認。
- グループ・複数人トークへの参加を許可する選択を画面で確認。
- 長期アクセストークンの発行を画面で確認。
- [配信試作](../apps/line-pilot/README.md)を作成。
- 内部処理と模擬通信の9項目のテストが合格。

## まだ確認できていないこと

- 接続情報を試作のローカル設定に入力したこと。
- Webhookの公開HTTPS接続先。
- Webhookの検証成功と有効化。
- 複数グループからの接続を受信できること。
- 実際のLINEアプリに、選んだ送り先だけへ到着すること。
- 本番の常設運用環境。

**LINE公式が対応していること、模擬テストが通ること、実際のLINEに到着することは、それぞれ別の検証段階。現時点では最後の段階は未実施。**

## 次の実機テスト

1. 手元の非公開設定に接続情報を入力する。
2. Webhook専用ポートに接続する公開HTTPSの接続先を用意する。
3. LINE側にURLを登録し、検証してWebhookを有効にする。
4. 試験用の全体・チームAグループにボットを招待する。
5. 管理画面で用途を割り当て、少数のテスト文を送る。
6. LINEアプリで送り先と到着を確かめ、退出時の扱いも確認する。

公開GitHubでの資料管理と、LINEボットを動かす公開接続先の準備は別の作業。リポジトリを公開しただけではボットは稼働しない。
