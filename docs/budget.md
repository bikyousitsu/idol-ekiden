# 予算と相談事項

料金確認日：2026年10月9日。これは支出提案であり、購入・契約・追加予算は未承認。

## 予算の考え方

主催者が自由に使える **10,000円** から、LINE配信費用・衣装・備品などを出したい。衣装は100均などを活用し、スパンコールや動物の耳、ちょんまげなどを用意する構想。

衣装や必要備品の数量・単価はまだ見積もっていない。総額10,000円を超える可能性も含め、運営に相談する。

## LINEの料金

| プラン | 月額（税込換算） | 月の配信枠 | 今回の位置づけ |
| --- | ---: | ---: | --- |
| コミュニケーション | 0円 | 200通 | 少人数の接続テストに使用する候補 |
| ライト | 5,500円 | 5,000通 | 本番で頻繁に自動配信する場合の候補 |
| スタンダード | 16,500円 | 30,000通 | 現在の規模では検討の中心にしない |

LINEの公式表示は有料プランを税別で掲載。上表は消費税10%を加えた金額。無料・ライトプランは追加配信不可で、上限に達すると配信が止まる。無料枠超過で自動的に有料プランに切り替わるものではない。

APIの有効化やトークンの発行そのものではなく、プランと配信方法・配信数によりLINEの費用が決まる。

出典：[LINE公式料金表](https://www.lycbiz.com/jp/service/line-official-account/plan/)、[Messaging APIの料金](https://developers.line.biz/ja/docs/messaging-api/pricing/)。2026年10月1日の改定はスタンダードの追加メッセージ料金についてのもの。上の固定料金・配信枠は確認日の公式資料に基づく。

## 配信数の例

自動通知（プッシュ配信）は **送る回数 × 届ける人数** で数える。参加者60人、仮に6チーム各10人として計算すると：

| 内容 | 計算 | 通数 |
| --- | --- | ---: |
| 全体グループへの通知20回 | 60人 × 20回 | 1,200通 |
| 各チームへの通知10回 | 10人 × 10回 × 6チーム | 600通 |
| 合計 | 上記二つの合計 | 1,800通 |

同じ人が全体とチーム両方の通知を受ける場合、それぞれの配信で数える。実際には運営メンバー、追加参加者、当月の事前テストなどの分も見込む。

60人への全体通知だけでも、3回で180通、4回で240通。無料200通で頻繁な全体自動配信を回すのは難しい。

## 無料に寄せる構成案

- 芸能ニュース、広告、細かい順位更新をダッシュボード中心にする。
- 普通のLINEグループで、運営者が手動で連絡する場面も組み合わせる。
- ボットへの「順位」などの問いかけに返信する方式を使う。Messaging APIの応答メッセージはLINEの配信通数にカウントされない。
- 自動通知の回数と対象を絞り、当月の残り配信枠を確認する。

返信方式は参加者からの操作が必要。任意のタイミングで送りたい通知と、問い合わせへの返信は使い分ける。応答時にAIを使う場合のAI費用は別。

## 10,000円から使う場合

| 項目 | 現在の見通し |
| --- | --- |
| LINE配信 | 無料構成なら0円。ライトを選ぶなら5,500円／月 |
| 衣装・応援グッズ | 金額未定。100均などを活用する案 |
| ミッション備品・印刷 | 金額未定。既存備品の利用も含めて確認 |
| AI利用 | モデル・利用回数未定。まだ実装・費用見積もりなし |
| サーバー・公開接続先 | 構成未定。まだ費用見積もりなし |

ライトを利用した場合、10,000円 − 5,500円 = **4,500円** がそれ以外に使える額。総額はまだ確定できない。

現状の試作はPC上の配信練習ができ、AI呼び出しもない。実機テストは、当月の無料枠が残っていれば少数の配信で試せる。公開接続先の費用は選定時に確認する。

## 運営に相談したいこと

1. 自由に使える10,000円を、この配信・衣装・備品に充てる方針でよいか。
2. 自動配信の演出と、衣装・ミッション備品のどちらをどの程度優先するか。
3. 無料構成と、LINE税込5,500円の構成をどう選ぶか。
4. 費用が10,000円を超える見積もりになった場合、内容を減らすか、追加予算を相談するか。
5. LINEを有料にする場合の契約月と、その後のプラン管理をどうするか。

支払い前に、人数・通知回数・衣装数量・必要備品を表にして総額を確かめる。
