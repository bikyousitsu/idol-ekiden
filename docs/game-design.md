# 資金・人気・ミッションの仕組み

更新：2026年10月9日。報酬額、費用、採点式、上限は未決定。

## 基本の循環

**ミッションで獲得する → 使い道を選ぶ → グループの活動や人気が変わる → 結果が全体に見える。**

資金は、貯まるだけの得点ではなく、グループを成長させるために使う。衣装は直接の勝敗要素にしない。

| 要素 | 役割 | 現在の位置づけ |
| --- | --- | --- |
| 推し活資金 | 衣装、宣伝、イベント開催、スキャンダル対応に使用 | 使える資源にする方針 |
| 衣装・小物 | 着る本人の気分と、観客の期待感を上げる | 直接の得点を付けない方針 |
| 獲得ファン数 | グループの成長・人気を示す | 勝敗を表す指標として検討中 |
| 情報 | ボーナス場所、イベントのお題などを知る | すぐ使える内容を候補にする |

## 古参ファンと新規ファン

参加者である上の年目は、所属グループの古参ファンとして固定する方向で検討。途中で他チームに移籍・推し変しなくてもゲームが成立するようにする。

変動する「新規ファン数」は、ゲーム内でイベント・動画・宣伝を見て獲得した架空の人数とする案。実際の参加人数やSNSのフォロワー数とは分けて扱う。

総合力を複数の能力値で表す案も当初出たが、現時点では獲得ファン数を中心に分かりやすくする方向を検討している。

## ミッションの種類

| 種類 | 主な参加の仕方 | 報酬の候補 |
| --- | --- | --- |
| アイドル活動 | 一年目が表現し、上の年目が撮影・応援・補助 | 人気、衣装 |
| 推し活 | 上の年目が挑み、一年目が応援や作戦で参加 | 資金、情報 |
| 合同活動 | チーム全員で協力 | 資金、人気 |

身体・協力系、即興表現、写真・動画撮影などを混ぜる。移動中のジャケット写真撮影や決めポーズなど、移動そのものが活動になる工夫も候補。

## 資金の使い道

| 用途 | 内容の候補 | 得点との関係 |
| --- | --- | --- |
| 衣装・応援グッズ | スパンコール、動物の耳、ちょんまげ、うちわなど | 購入自体に得点を付けない |
| 宣伝 | 全体LINEや画面にグループ名・写真・宣伝文を掲載 | 人気を確実に少し増やす案 |
| ミニイベント | 短いライブ、撮影会、握手会風の企画などを開催 | 実施・成功・評価で人気を増やす案 |
| 動画の宣伝 | 撮った動画をゲーム内で広める | 動画制作と資金の使い道をつなぐ案 |
| スキャンダル対応 | 口止め料などを払う | トラブル対応の選択肢にする |

宣伝は確実性、イベントは挑戦による大きな成長、といった違いを作る案。金額や効率は未決定。衣装をミッション報酬で直接渡すか、衣装屋で購入するか、両方にするかも未決定。

## スキャンダルイベント

「週刊ケイテキ」などの架空媒体から記事が届く構想。例：朝食を毎日二回食べていた疑惑。

対応案は、口止め料を払う／指定語を入れた釈明会見をする／話題を使った寸劇や宣伝で人気を得る、など。選べる対応・費用・結果をその場で明示し、複雑な推理は必要としない形を検討する。

チーム限定LINEで事前通告し、対応結果を全体に記事として流す演出も候補。発生回数、公平性、失敗時の減点幅、公開までの時間は未決定。

## 動画制作イベント

| 候補 | 内容 | 想定尺（仮） |
| --- | --- | --- |
| TikTok風ショート | ダンス、決めポーズ、短いコント | 15〜30秒 |
| YouTube企画風 | チャレンジ、漫才、アイドル紹介 | 30〜60秒 |
| デビュー告知 | 名前・キャッチコピー・意気込み | 短くまとめる |

まずは撮影した動画を運営へ提出し、ゲーム内の再生数やファン数で表現する案。実際のSNSに公開するかは未決定。上の年目は撮影・進行などで関われる。編集にかかる時間、提出方法、審査、撮影場所はこれから決める。

## 運営評価とAI

運営が少数の評価項目を入力し、AIがファン数を追加するアイデアが出た。

検討案は、運営が「やり切り度」「工夫・個性」「巻き込み度」を三段階程度で入力し、共通式でファン数を計算する仕組み。AIには、その結果に応じた芸能ニュースや架空のコメントを作らせる。

これは提案段階。評価項目・配点・成功条件・計算式・AIの担当範囲は未決定。具体的な記事を作るなら、運営が活動内容を一言添える入力も候補。

## バランス確認で見ること

- チーム人数や得意分野が違っても参加できるか。
- 道中の投資に複数の合理的な選択肢があるか。
- 上位がさらに有利になる循環が強すぎないか。
- 最後まで挑戦する理由と、積み重ねが報われる仕組みが両立するか。
- 1ミッションの所要時間・待ち時間・運営の処理量が現実的か。
