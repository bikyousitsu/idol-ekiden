| 主役 | 一年目をアイドル、上の年目をファン役にする |
| 移動 | チームで一緒に行動する |
| 規模 | 約60人、2〜3時間の想定 |

## 主催者から挙がった案

- 宣伝、ミニイベント開催、スキャンダルの口止め料に資金を使う。
- 古参ファンは固定し、それ以外の新規ファン数を変動させる。
- 運営の入力とAIで活動評価・ファン獲得を表現する。
- YouTube・TikTok風の動画制作イベント。
- 道中の順位でライブの出演条件に差を付ける。
- ハイリスク・ハイリターンの演目や、順位順の演目選択。
- 最後にもう一度人気獲得の機会を作り、優勝を決める。

## 採用がまだ決まっていない提案

- 6チーム×約10人、フィナーレに約40分を確保する想定。
- 勝敗の指標を獲得ファン数一つに絞る。
- 運営の評価三項目と、共通式によるファン数計算。
- AIをニュース・コメントの生成担当にする。
- 演目の選択と難度の選択を分ける。
- 衣装の交換、衣装屋、購入と直接報酬の併用。
- 動画を運営提出にして、紹介映像に使う。
- 釈明会見や話題に乗っかる対応をスキャンダルの選択肢にする。

## 進める順番

1. **運営への進捗共有と予算相談**：このリポジトリを共有し、実施条件と費用の考え方を確認する。
2. **LINEの実機テスト**：少人数・少数配信で全体とチームへの送り分けを確かめる。
3. **最後のライブと勝敗の設計**：参加者に残したい体験、順位のご褒美、逆転幅を決める。
4. **資金と人気の設計**：数値や価格を決め、仮のチーム行動でバランスを確認する。
5. **ミッションと運営動線**：場所、スタッフ、備品、時間割を確定する。
6. **制作**：説明スライド、配布物、台本、演出、ダッシュボード、配信連携を作る。
7. **リハーサル**：入力・集計・通信・ステージ転換を通して確認する。

企画を詰める相談と、LINEの小さな接続試験は並行して進められる。本番機能を増やす前に、実機テストと予算の見通しを確かめる。
