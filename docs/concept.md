# 企画の目的と全体構成

> **初期案の記録（2026年10月9日ごろ）です。** 現行の運営ルールは [制作パック](production/README.md) と [共通ルール・料金表](production/common-rules.md) を優先してください。以下には、北18条でのフィナーレ、衣装を採点しない案、自動配信や当時の価格など、現在案と異なる検討内容が残っています。

更新：2026年10月9日。具体的な時間割・チーム数・場所は未確定。

## 駅伝とは

恵迪寮や北海道大学構内、札幌市街などをフィールドに、移動しながらチームごとにミッションをこなす寮祭の企画。今回のテーマは「アイドル」。

## 大切にする体験

1. 一年目が主役として輝ける。
2. 上の年目も、自分たちの推しを育て、送り出す役割を楽しめる。
3. 体を張る・協力する・移動する楽しさがある。
4. 道中に獲得したものや活動が、最後のステージにつながる。
5. ルールを読み解くことに長けた人だけが活躍する形にしない。

前回の反省は、情報戦の難易度が高く、ついていけない人が出たこと。今回も情報報酬は候補にあるが、秘密を複雑に組み合わせて推理するより、すぐ行動に使えるものを中心に検討する。

## 役割と移動

| 役割 | 担当 | 体験 |
| --- | --- | --- |
| アイドル | チーム内の一年目 | 表現活動、衣装選び、グループの方向性決定、ステージ出演 |
| 古参ファン | チーム内の上の年目 | ミッションでの資金集め、撮影・応援・演出の準備、推しへの投資 |

**アイドルと古参ファンは一緒に移動する。** ミッションごとに誰が主役になるかを切り替える。上の年目が挑む場面でも、一年目が作戦・応援・衣装選びなどに関われるようにする案。

## 全体の流れ

| 段階 | 内容 |
| --- | --- |
| 集合・導入 | チーム分け、アイドル名などの設定、ルール説明 |
| 道中 | ミッション、衣装獲得、宣伝、ミニイベント、動画撮影、突発イベント |
| 集合・ライブ | 所定の時刻に北18条ステージ前へ集合し、全グループが披露 |
| 最終局面 | 最後の人気獲得・投票などを行う構想。方法は未決定 |
| 表彰 | 最も人気の高いグループにレコード大賞風の賞を授与 |

## 規模と時間

- 全体で2〜3時間。
- 参加者は約60人を想定。
- 6チーム×約10人は、検討用の仮置き。チーム数は未決定。
- 一年目の人数、運営人数、開催日、使える場所、ステージ設備は未確認。
- 6チームなら紹介・披露・転換を各4〜5分として24〜30分。最終判定・表彰まで含めた約40分の確保は検討案であり、確定した時間割ではない。
