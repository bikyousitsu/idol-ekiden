# アイドル駅伝

**一年目がアイドルになり、上の年目が古参ファンとして支える、恵迪寮祭のチーム型イベント。**

チームで寮・北大構内・札幌市街などを移動し、ミッションで資金や衣装を獲得。資金を宣伝やイベントに使ってグループを成長させ、最後は北18条ステージで全グループがライブを行います。

> このリポジトリは、2026年10月9日までの相談を整理した企画のたたき台です。細かいルール、採点、予算の支出は未確定です。LINE配信の試作は内部テスト済みですが、実際のLINEへの到着はまだ確認していません。

## まず知ってほしいこと

| 項目 | 現在の方向性 |
| --- | --- |
| 目的 | 一年目が輝き、上の年目も推しを育てる楽しさを味わう |
| 規模 | 参加者約60人、全体で2〜3時間を想定 |
| チーム | 一年目＝アイドル、上の年目＝古参ファン。一緒に移動する |
| 道中 | シンプルな身体・協力・表現・移動ミッションを中心にする |
| 成長 | 稼いだ資金を宣伝・ミニイベント・スキャンダル対応などに使う |
| 衣装 | 人気の点数とは直接結びつけず、気分と見た目を盛り上げる |
| フィナーレ | 北18条ステージで全グループが披露し、最終的な人気で優勝を決める構想 |
| 連絡 | 全体と各チームのLINEグループに、連絡やニュースを送り分ける |

前回は情報戦についていけない参加者が出たため、今回は「動けば分かる」「一緒に挑める」「活動が目に見える」を大切にします。

## イベントのイメージ

**ミッションに挑戦 → 資金・衣装・情報を獲得 → 宣伝やイベントに投資 → 人気が成長 → ライブ → 最終判定・表彰**

一年目がアイドル活動に挑む場面、上の年目が推しのために体を張る場面、全員が協力する場面を混ぜる案です。衣装はスパンコールや動物の耳、ちょんまげなど、華やかさとおもしろさを両立させたいと考えています。

## 現在の進捗

- 企画の基本構想と、アイドル／古参ファンの役割を整理。
- 全体・特定チーム・全チーム個別に送り分けるLINE配信画面を試作。
- 送り先、署名確認、二重送信の防止、退出後の扱いなど、9項目の内部テストに合格。
- LINE公式アカウントを作成。Messaging APIを有効化。
- グループ参加を許可し、アクセストークンを発行。
- Webhookの公開接続先、実際のLINEでの送信試験、AIニュース、得点管理はこれから。

## 費用について相談したいこと

自由に使える **10,000円** から、配信費用・衣装・備品などを出したいという提案です。

LINEは月200通までの無料プランで試せます。ただし、60人に頻繁に自動配信する本番では、月5,000通のライトプラン **税込5,500円／月** が候補になります。残りは4,500円となり、衣装・備品・AIやサーバー費用を合わせると10,000円を超える可能性があります。支出や追加予算はまだ決まっていません。

詳しい配信数の例、無料に寄せる方法、相談したい項目は [予算資料](docs/budget.md) にまとめています。
